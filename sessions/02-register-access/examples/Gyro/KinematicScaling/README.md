# KinematicScaling

A scaling example showing how integer sensor counts map to acceleration or angular-rate units.

## Files in this folder

- `KinematicScaling.ino`

## How to use these examples

Read the source comments and the lesson or project README one level above before compiling or running a file. Arduino sketches should be opened as individual sketches in Arduino IDE unless a PlatformIO project README says otherwise. Python tools run on the host computer and may require serial-port selection and Python packages. These files are preserved teaching examples; this reorganization does not change their implementation.
