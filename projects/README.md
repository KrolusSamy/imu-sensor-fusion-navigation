# PlatformIO projects

Each subfolder here is an independent project or teaching scaffold. The three folders with a `platformio.ini` are separate PlatformIO workspaces; `imu-guide-starter` is an architecture exercise and is not ready to build as supplied. Open a workspace folder, rather than this parent folder, in PlatformIO.

- [GY-91 PlatformIO](gy91-platformio/README.md): introductory modular GY-91 sensor access and kinematics.
- [IMU Guide starter scaffold](imu-guide-starter/README.md): architecture-only starting point; not ready to build as supplied.
- [IMU Guide](imu-guide/README.md): modular MPU6050/GY-91 sensor handling and visualization support, useful as the implemented follow-on.
- [Madgwick 9-DoF](madgwick-9dof/README.md): nine degree of freedom orientation fusion with dedicated middleware.
